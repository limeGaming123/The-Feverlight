# Author Notes

This vault is designed so you can keep adding new ideas without everything becoming messy.

## Suggested workflow

1. Put new rough thoughts in [[00 Start Here/Inbox]].
2. Turn good ideas into proper notes in the correct folder.
3. Link everything to at least one existing note.
4. When a note is ready for the blog, set `draft: false` in the frontmatter.
5. If a note is private or unfinished, set `draft: true`.

## Naming style

Use clear titles like:

- `Character - Name` only if you have lots of characters.
- `Chapter 01 - Title` for drafts.
- `Magic System - Topic` for world rules.

This vault mostly uses natural titles because they look nicer on Quartz.
