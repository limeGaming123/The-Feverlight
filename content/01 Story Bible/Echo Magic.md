# Echo Magic

Echo Magic lets [[02 Characters/Kael Veyr|Kael Veyr]] hear memories left behind in people, objects, and places.

At first, it seems like a passive ability.

Then Kael learns he can touch an echo and pull it closer.

## Simple uses

- hearing what happened in a room
- sensing who touched an object
- finding a path someone took
- feeling the emotional weight of a memory

## Dangerous uses

- pulling an old state of a body into the present
- hearing memories that have not happened yet
- trapping himself inside a memory
- changing something by accident

## Cost

Each use weakens Kael's sense of now.

He may:

- answer questions someone has not asked yet
- remember conversations that never happened
- forget whether Lira is alive right now or only alive in an echo
- hear future versions of himself warning him to stop

## Story rule

Echo Magic should be intimate, emotional, and scary. It is strongest when Kael touches something connected to love, grief, fear, or guilt.
